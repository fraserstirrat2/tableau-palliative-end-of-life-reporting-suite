# Admissions Dashboard — Parameters

The Admissions Dashboard uses two Tableau parameters to control the analytical view.

## Time Window

Allows the user to switch the analytical period before death between:

- 7 Days
- 14 Days
- 3 Months
- 6 Months
- 12 Months

The selected value feeds into reusable calculated fields for admissions, patients, bed days and deaths.

## Trend Selector

Allows the user to switch the main trend chart between:

- Admissions Per Death
- Average Length of Stay

Together, these parameters allow one dashboard to support multiple analytical questions without duplicating separate dashboard pages for each measure or time period.
