# Change Analysis

This group contains year-on-year change calculations retained as part of the wider Admissions workbook calculation layer:

- Yearly % Change - Admissions per death
- Yearly % Change - Patients per bedday

## Purpose

These fields provide additional analytical context by comparing a measure with its previous financial-year value. They are documented even where they are not the primary focus of the current main dashboard view because they form part of the workbook's development history and technical evidence.

- [Yearly % Change - Admissions per death](01-yearly-change-admissions-per-death.png)
- [Yearly % Change - Patients per bedday](02-yearly-change-patients-per-bedday.png)
