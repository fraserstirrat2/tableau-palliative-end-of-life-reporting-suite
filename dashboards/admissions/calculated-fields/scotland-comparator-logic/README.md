# Scotland Comparator Logic

This group contains the calculations used to retain a national comparator alongside the selected dashboard view:

- Scotland Admissions (LOD)
- Scotland Beddays (LOD)
- Scotland Deaths (LOD)
- Scotland Patients (LOD)
- Scotland Average Admissions per Death
- Scotland Average Length of Stay

## Purpose

The comparator provides a consistent Scotland-level reference point so a selected analytical result is not interpreted in isolation.

The workbook uses dedicated Level of Detail calculations for the underlying Scotland admissions, patients, bed days and deaths measures, which then support the derived national comparator values.
