# Admissions Dashboard — Technical Case Study

This directory documents the Tableau development of the Admissions Dashboard within the wider palliative and end-of-life care reporting suite.

The case study is designed as a layered portfolio: the main repository README will provide the employer-facing overview, while this section provides deeper evidence of the Admissions dashboard's analytical design, Tableau implementation, validation process and development history.

## What this dashboard supports

The dashboard allows users to explore hospital activity before death across multiple analytical windows: **7 days, 14 days, 3 months, 6 months and 12 months**. It combines user-controlled filters with parameter-driven trend measures, a Scotland comparator and a supporting summary table.

The public portfolio evidence uses approved **Scotland-level views**. More granular operational views and source-level material are intentionally not reproduced in this repository.
