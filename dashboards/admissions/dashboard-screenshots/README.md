## What these screenshots demonstrate

Across the evidence set, the dashboard shows:

- the **Time Window** parameter updating the analytical period;
- the **Trend Selector** switching the main measure;
- different approved filter states;
- the Scotland comparator remaining available for context;
- the yearly summary table updating alongside the trend;
- the same workbook structure supporting multiple analytical questions.

The filter combinations are intentionally broader Scotland-level examples suitable for a public portfolio. More granular operational selections are not reproduced here.

## How these should be used in the case study

The main Admissions README should not display all ten images consecutively. Instead, it uses a curated example and links here for the complete technical evidence set.

This keeps the employer-facing case study readable while still giving an interviewer or technical reviewer the option to inspect every approved dashboard state.
