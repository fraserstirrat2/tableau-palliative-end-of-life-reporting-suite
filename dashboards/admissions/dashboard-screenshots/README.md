# Admissions Dashboard — Screenshot Evidence

This folder contains the full set of approved Scotland-level dashboard screenshots selected for the public portfolio.

The ten views are intentionally retained because they demonstrate the dashboard under different combinations of:

- all five analytical time windows: 7 days, 14 days, 3 months, 6 months and 12 months;
- both trend-selector measures: Admissions Per Death and Average Length of Stay;
- different approved filter states.

The purpose is not to present ten near-identical images in the main case study. Instead, the main Admissions README will show a small curated selection and link here for the complete evidence set.
