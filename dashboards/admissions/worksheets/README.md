# Admissions Dashboard — Worksheets

This folder documents all seven Tableau worksheets supplied for the Admissions Dashboard.

## Analytical worksheets

- Admissions Per Death trend chart
- Average Length of Stay trend chart
- Admissions summary table

## Navigation and information worksheets

- Home icon
- Help icon
- Information icon
- Go-To icon

Keeping these worksheets visible in the technical case study demonstrates how the finished dashboard is assembled from separate analytical and interface components rather than presenting only the final dashboard canvas.
