# Admissions Dashboard — Worksheets

This folder documents all seven Tableau worksheets supplied for the Admissions Dashboard. Retaining these images shows how the final dashboard is assembled from separate analytical and interface components rather than presenting only the finished canvas.

## Analytical worksheets

1. [Admissions Per Death trend chart](05-admissions-per-death-line-chart.png)
2. [Average Length of Stay trend chart](06-average-length-of-stay-line-chart.png)
3. [Admissions summary table](07-summary-table.png)

The two trend worksheets support the Trend Selector behaviour, while the summary table presents the underlying yearly admissions, patients, bed days and deaths alongside the visual trend.

## Navigation and information worksheets

1. [Go-To icon](01-go-to-icon.png)
2. [Help icon](02-help-icon.png)
3. [Home icon](03-home-icon.png)
4. [Information icon](04-information-icon.png)

These worksheets support navigation, help and interpretation within the workbook. The Information control is particularly important because the dashboard includes methodological caveats — such as the cause-of-death selection rule — that users need to understand when applying filters.

## Why worksheet-level evidence is included

A final dashboard screenshot demonstrates presentation quality, but it does not show how the workbook is structured. Keeping the worksheet evidence allows a technical reviewer to see that the reporting product is composed from reusable analytical views and dedicated interface components.
