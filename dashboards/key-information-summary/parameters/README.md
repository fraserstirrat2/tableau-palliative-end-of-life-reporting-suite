# Key Information Summary — Parameters and User Controls

This folder will document any parameters and user controls that genuinely drive the KIS dashboard.

## Controls to identify

For each control, record:

```text
Name
Type: parameter / filter / dashboard action
Allowed values or configuration
Affected worksheets
Supporting calculation (if any)
Reporting purpose
```

If KIS uses only standard filters and no meaningful parameters, state that clearly rather than creating artificial parameter evidence.

## Evidence to add

Add screenshots of the real Tableau configuration only where they help a technical reviewer understand the delivered interaction.
