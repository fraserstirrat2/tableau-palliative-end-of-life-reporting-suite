## Why the paired states matter

The screenshots are not included simply to show different numbers.

### 2024/25 pair

The Accesses and Patients screenshots demonstrate the main **KIS View** interaction:

```text
same dashboard
same Financial Year / Scotland context
        ↓
KIS Accesses  ↔  KIS Patients
```

### 2022/23 pair

The second pair demonstrates two interactions together:

- **KIS Access Measure** changed to Portal Accesses;
- **KIS View** then changed from Accesses to Patients.

That provides stronger evidence of the dashboard architecture than publishing multiple screenshots with only superficial formatting differences.

## Public-safety rule

Dashboard screenshot evidence must remain at approved **Scotland level**.

Do not upload public screenshots showing:

- individual GP practices;
- local Cluster values;
- local HSCP/Health Board analytical detail if not approved for the portfolio;
- underlying data/export views;
- workbook data-source previews;
- internal file paths, credentials or unpublished notes.

The technical worksheet/parameter/calculated-field screenshots are documented separately because their purpose is to show Tableau implementation rather than publish granular analytical results.
