# Key Information Summary — Calculated Fields

This folder will document the calculated fields that are genuinely relevant to the KIS dashboard.

## Calculation architecture

Group calculations by purpose once reviewed, for example:

- measure/metric logic;
- display/selector logic;
- labels or helper fields;
- geography/time logic;
- KPI/status logic.

For each retained field document:

```text
Field name
Purpose
Input fields / parameter dependency
Plain-English logic
Why it exists in the dashboard
Screenshot of the Tableau calculation
```

Distinguish source fields from Tableau calculations and avoid documenting unused/helper fields that do not contribute to the delivered dashboard.
