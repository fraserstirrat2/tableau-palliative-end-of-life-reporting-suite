# MSG5 — Dashboard Screenshots

This folder contains the approved public dashboard-level evidence for the **Last 6 Months of Life by Setting** dashboard.

The evidence set is intentionally small: it demonstrates the two main analytical states clearly without uploading every possible Council Area or filter combination.

## Evidence set

| File | Purpose |
| --- | --- |
| `01-L6MOL-Scotland-Level-Dashboard-Overview-Numbers.png` | Final Scotland-level **Numbers** state showing absolute setting-level bed days across 2020/21–2024/25p |
| `02-L6MOL-Scotland-Level-Dashboard-Overview-Percentages.png` | Final Scotland-level **Percentages** state showing the proportional distribution across the same four settings and years |

## Numbers view

![MSG5 Scotland Numbers](01-L6MOL-Scotland-Level-Dashboard-Overview-Numbers.png)

The Numbers state shows the four setting-level bed-day measures as a stacked bar plus detailed table.

## Percentages view

![MSG5 Scotland Percentages](02-L6MOL-Scotland-Level-Dashboard-Overview-Percentages.png)

The Percentages state uses the same dashboard structure while switching to the four supplied percentage measures. The screenshot also demonstrates contextual tooltip information such as Financial Year, the active percentage, Deaths and Possible Bed days.

## Information and navigation evidence

The dashboard's Information, Home, Help and Go To implementation evidence is stored separately in the [Worksheets](../worksheets/README.md) section so this folder remains focused on the two final analytical dashboard states.

The public Information view explains the purpose of the dashboard, the four care settings, Numbers / Percentages, financial-year and Council Area context, chart/table interpretation, tooltip use and the main interpretation caveats.

## Why there is no Council Area analytical screenshot

The managed workbook supports Council Area reporting, but the public portfolio boundary is **Scotland-level analytical evidence only**. The parameter and calculated-field configuration demonstrate how geography selection works without publishing local analytical results.

## Public portfolio rule

Only screenshots suitable for public portfolio use are committed. The evidence does not expose source files, internal URLs, credentials, underlying datasets, operational code or unnecessary granular analytical combinations.
