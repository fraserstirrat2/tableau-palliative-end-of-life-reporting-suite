# MSG5 — Tableau Worksheets

This folder will document the worksheets used to assemble the **Last 6 Months of Life by Setting** dashboard.

The current evidence indicates a compact worksheet architecture rather than a large number of analytical sheets.

## Analytical worksheets observed so far

| Worksheet | Role |
| --- | --- |
| **MSG - Bed Days by Setting** | Detailed table for absolute bed-day values |
| **MSG - Bed Days by Setting %** | Detailed table for percentage distribution |
| **MSG - Settings Breakdown (Bar)** | Stacked bar for the Numbers view |
| **MSG - Settings Breakdown (Bar) (2)** | Stacked bar for the Percentages view |

## Shared interface worksheets

The dashboard also uses the reporting-suite navigation/help components:

- Home
- Go To
- Help
- Information

These are separate worksheets in the Tableau workbook and are used consistently across the wider reporting suite.
