# Service Utilisation — Parameters and User Controls

This folder will document the parameters, filters and actions that genuinely drive the Service Utilisation dashboard.

For each control record:

```text
Name
Type: parameter / filter / dashboard action
Configuration or allowed values
Affected worksheets
Supporting calculation (if any)
Reporting purpose
```

If the dashboard relies primarily on standard filters and contains few/no meaningful parameters, document that accurately rather than creating artificial complexity.
