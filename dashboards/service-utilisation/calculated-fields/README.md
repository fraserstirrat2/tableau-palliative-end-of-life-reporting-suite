# Service Utilisation — Calculated Fields

This folder will document the calculated fields that genuinely contribute to the Service Utilisation dashboard.

Group the final calculations by purpose, such as:

- service-use measure logic;
- rate/percentage logic;
- parameter/display switching;
- labels/helper fields;
- time/geography logic;
- KPI/status logic.

For each retained field document:

```text
Field name
Purpose
Input fields / parameter dependency
Plain-English logic
Why it exists in the dashboard
Screenshot of the Tableau calculation
```

Distinguish source columns from Tableau calculations and omit unused fields.
